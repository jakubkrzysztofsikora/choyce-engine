# ElevenLabs Generated Audio

All assets under `data/audio/voice/`, `data/audio/sfx/eleven/`, and
`data/audio/music/` were generated via the ElevenLabs API
(`scripts/audio/generate_eleven_assets.py`).

- **Voice lines** (Polish kid-friendly mascot) — `text-to-speech` endpoint,
  model `eleven_multilingual_v2`, voice id `XB0fDUnXU5powFXDhCwa`
  (Charlotte).
- **Sound effects** — `sound-generation` endpoint.
- **Music loops** — `music` endpoint, model `music_v1`, 30 s loops.

## Usage rights

Under the ElevenLabs Terms of Use, audio generated by paid accounts can
be used in commercial products including games. See the ElevenLabs
[Terms of Service](https://elevenlabs.io/terms-of-use) for the canonical
statement and any per-tier restrictions on the account that generated
the assets.

## Regenerating

Set `ELEVENLABS_API_KEY` and re-run:

```
ELEVENLABS_API_KEY=sk_... python3 scripts/audio/generate_eleven_assets.py
```

The script is idempotent: files already on disk are skipped. Delete a
file to force its regeneration.
