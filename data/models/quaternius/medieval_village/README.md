# Medieval Village MegaKit (Standard)

This directory contains the Godot/glTF subset of Quaternius' **Medieval Village
MegaKit [Standard]**, supplied locally with the project. It is dedicated to the
public domain under CC0 1.0.

The starter homestead uses the modular textured wall, roof, door, and chimney
pieces as a real-size house shell. Keep it as a cohesive kit; do not mix its
parts with untextured primitive geometry in player-facing locations.
