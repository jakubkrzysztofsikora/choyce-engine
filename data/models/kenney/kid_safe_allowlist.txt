# kid_safe_allowlist.txt
#
# One bundled CC0 prop per line. Format:
#   <repo-relative-path> [| <category>] [| <display_name_pl>]
#
# Category and display name are optional — KenneyAssetCatalogAdapter
# infers both from the path when omitted. Categories use the CAT_*
# strings on AssetCatalogEntry (TREES_PLANTS, FOOD, BUILDINGS, BLOCKS,
# ANIMALS, VEHICLES, DECORATION, CHARACTERS).
#
# RULES:
#   1. Explicit allow only. New packs need a human pass before lines land here.
#   2. No weapons, monsters, prisoner skins, blood textures. KayKit
#      adventurers/assets/ has bows + axes — those go to the internal
#      ADVENTURERS_GEAR bucket and stay out of the BUILDER palette.
#   3. Keep this file under ~500 lines; bigger catalogs slow the kid
#      down. Curate the best representatives.
#
# CI gate (.github/workflows/notices-gate.yml) verifies that every path
# below points to a file checked into the repo.
# ---------------------------------------------------------------------
