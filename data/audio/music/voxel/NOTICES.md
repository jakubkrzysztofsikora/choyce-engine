# Music Attribution — voxel phonk pack

All tracks in this directory were sourced from [Freesound](https://freesound.org/)
under the **Creative Commons 0 (CC0 1.0 Universal — Public Domain Dedication)**
license. Attribution is not legally required, but contributors are listed
here as a courtesy and as an audit trail for license review.

Tracks have been passed through `scripts/audio/moderate_imported_music.py`
which runs an ElevenLabs Speech-to-Text pass on each MP3 and rejects any
track whose transcript matches the `rules_pl.json` word list (violence,
weapons, drugs, gambling, profanity, adult content, horror). The current
log lives at `MODERATION_LOG.md` next to this file.
