# SimpleWater DUDV texture

`simplewater_dudv.png` is sourced from the user-supplied
`3d-simplewater` package and is used by the Godot 4 Adventure river shader.

- Copyright © 2016 Khairul Hidayat
- License: MIT
- Original package: `3d-simplewater`

The original Godot 3 viewport/reflection script is not used. The runtime uses
only the texture in a Godot 4 shader, while the project keeps its own Area3D
water-volume and child-safe wading behaviour.
